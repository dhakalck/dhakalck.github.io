# Chandra Dhakal, PhD — Personal Website

Professional portfolio website for Dr. Chandra Dhakal, Health Economist at the CDC Foundation.

🌐 Live: [https://dhakalck.github.io](https://dhakalck.github.io)

## Structure

- `index.html` — Home: hero with headshot, about, research themes, selected publications, news
- `research.html` — Research agenda and themes
- `publications.html` — Full peer-reviewed publication list + working papers
- `teaching.html` — Teaching philosophy, courses, mentoring, capacity building
- `cv.html` — CV highlights + downloadable documents
- `contact.html` — Contact information
- `style.css` / `script.js` — Shared design system and interactions

## Documents

- `Chandra_Dhakal_CV.pdf` — Academic CV
- `Chandra_Dhakal_Resume.pdf` — Two-page professional resume
- `Research_Statement.pdf` — Research statement
- `Teaching_Statement.pdf` — Teaching statement
- `Extension_Statement.pdf` — Extension statement
- `References.pdf` — References

Replace any PDF with a newer version under the same filename to update the download.
